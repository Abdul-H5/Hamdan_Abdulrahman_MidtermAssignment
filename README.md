# Dr Nut Soda Website — Midterm Assignment
 ## Project Overview

This project is a responsive, mobile-first website created for the Web Development 1 Midterm Assignment in the Interactive Media Design program.

The goal of the assignment was to design and build two fully responsive boxed layout web pages using semantic HTML, a custom CSS grid system, and modern typography while following a structured design plan.

The website represents a fictional beverage brand called Dr Nut Soda Co., which produces unique nut-infused carbonated drinks.

## Live Project Description

The website showcases:

A branded homepage introducing the product

A products page displaying the soda lineup

A responsive navigation system

A custom grid layout

Mobile-first responsive design

Consistent typography and visual styling

The design focuses on clean structure, strong hierarchy, and usability across devices.

## Design Decisions

Key design choices were made to emphasize:

Strong readability

Clear information hierarchy

Consistent branding

Balanced spacing

Modern clean UI style

The boxed layout was chosen to create a professional, contained presentation rather than a full-width layout.

## How to Run the Project
